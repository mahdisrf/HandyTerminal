# HandyTerminal

This repository contains `HandyTerminal`, a simple Avalonia-based terminal command manager.
## Download

if you can see this
1- look for Releases on the right side of browser click on it 
2- download the HandyTerminal.v.1.0.0.zip
3- unzip it in your device 

find handytermnal file and run it

ps : if its not executable , right click chose properties check  executable or run as program close the window and run it again

### Notes

- The published Linux binary is the one command-line executable file named `HandyTerminal`.
